# Spoti-Chan

Учебное музыкальное приложение на **React + Tailwind CSS** и **Node.js + Express**.
Текущая версия **0.2**: интерфейс каталога, Music Finder и локальное избранное.

## Что работает

- Адаптивный интерфейс: обзор, Music Finder, избранное и диалог трека.
- Загрузка каталога из Express API, поиск по названию/исполнителю и фильтры по жанру.
- Поиск по описанию с примерами и объяснением совпавших тегов.
- Избранное в localStorage, сохранение между перезагрузками на том же origin.
- Состояния загрузки, пустого результата, ошибки сервера и повтор запроса.

**Пока это демоверсия.** В каталоге четыре записи с метаданными, аудио нет.
Music Finder использует словарь правил и теги, а не Gemini. Графика карточек декоративная,
не является обложками альбомов. Ключи API и облачные сервисы для запуска не нужны.

## Быстрый запуск

Нужны **Node.js 22.12+** и npm. Из папки проекта:

```sh
npm ci
npm run build
npm start
```

Открыть [http://localhost:3001](http://localhost:3001).
Express обслуживает API и собранный frontend из `dist/`.
`npm start` самостоятельно не собирает frontend — после изменений сначала выполнить `npm run build`.

### Разработка

```sh
npm run dev
```

Одна команда запускает backend и Vite. Frontend: [http://127.0.0.1:5173](http://127.0.0.1:5173),
API: [http://localhost:3001](http://localhost:3001). Если порт frontend занят, Vite напечатает другой адрес.
Для независимого запуска есть `npm run dev:server` и `npm run dev:client` (в разных терминалах).

Переменная `PORT` меняет порт Express. Если меняется порт API, нужно также изменить
`server.proxy` и `preview.proxy` в `vite.config.js`; по умолчанию они используют `3001`.
`npm run preview` показывает сборку Vite и требует отдельно запущенного backend.

```sh
npm test        # проверки HTTP API и обработки ответов на frontend
npm run build  # production-сборка
```

## Music Finder

`POST /api/finder`, заголовок `Content-Type: application/json`:

```json
{ "description": "Что-то похожее на Linkin Park, но с женским вокалом" }
```

Ответ содержит `mode: "demo-tags"` и `tracks`. Для примера выше: **Going Under — Evanescence**,
затем **Ice Queen — Within Temptation**. Поле `matchedTags` объясняет подбор.
Описание должно содержать от 1 до 500 символов; неизвестный запрос возвращает пустой список.

Распознаются четыре исполнителя из каталога, rock/рок, metal/метал, alternative/альтернативный,
symphonic/симфонический, pop/поп, funk/фанк, dance/танцевальный, energetic/энергичный,
female/женский и male/мужской вокал. Сложные отрицания и смешанный вокал не поддерживаются.

Другие методы: `GET /api/health`, `GET /api/tracks`.

## Структура

```text
src/             React, оформление, клиент API и проверки ответов
public/          favicon
server/          Express API, каталог и правила подбора
docs/TZ.md       техническое задание и критерии приёмки
vite.config.js   сборка, Tailwind и proxy API
```

Избранное хранится только в текущем браузере и origin. Например, localhost:3001 и
127.0.0.1:5173 имеют отдельные коллекции. При запрете хранилища интерфейс выводит предупреждение.
